# Analysis proposal contract

Your role name is a starting perspective, not a restricted operation menu.

Start from your assigned evidence source and return one executable data proposal. State the observed issue, evidence paths and versions, proposed data change, assembly procedure, expected training exposure under the fixed token cap, comparison round, predicted observation, and uncertainties. Separate measurements from interpretations. A score difference alone does not prove an intervention worked.

Inputs are immutable. Write scratch products only inside this task's directory. Do not edit the shared pool, formal recipe, training parameters or benchmark answers. The meta agent owns the realized data and final decision. Persist your report with the task id, round, role and input digest through `autosft.agents.search_tasks persist`.

Before using either shared data operator, read and follow the applicable skill: `${AUTO_SFT_REPO_ROOT}/skills/shared/row-analysis/SKILL.md` for per-row analysis or `${AUTO_SFT_REPO_ROOT}/skills/shared/pool-rewrite/SKILL.md` for source-grounded rewrites. These operators are optional.
